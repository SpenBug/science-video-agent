# 口播稿规则与合规红线（S3 / S5 用）

> 本文件领域无关，任意科普方向通用。领域特有的红线（如数模的「不代写代做 / 不承诺获奖」）
> 由用户在会话里补充，或写在领域自己的资料里；本清单是底线。

---

## 1. 事实核对协议（S3）

写进视频的每一句「事实性内容」必须能归入三类口径之一：

| 口径 | 定义 | 口播要求 | 例子 |
|---|---|---|---|
| **事实** | 有权威出处（官方文档、法条、标准、论文、权威统计） | 直接说，可注明来源 | 「国家标准 GB/T 里写明……」 |
| **实算/实测** | 自己跑数据 / 做实验得到的 | 必须带「大约」「实测出来」，不承诺普适 | 「我们实测下来大概是 60%」 |
| **经验口径** | 行业常识、个人经验，无硬出处 | 必须带「通常」「大概」，不当硬结论讲 | 「通常建议先做小样本」 |

**出处表格式**（贴给用户确认）：

```
| 结论 | 口径 | 出处 | 原文摘录 |
```

**核对原则**：
1. 规则类、条款类、处罚类内容**必须逐字对权威原文**，改写要保守——宁窄勿宽。
2. 找不到权威出处的说法，一律降级为「经验口径」加软化词。
3. 统计数字注明**年份与统计口径**（不同年份口径可能完全不同）。

## 2. 合规红线（底线，违反必返工）

1. **不编造**：权威来源没有的内容、数据、条款、结论，一个字都不许造。
2. **不绝对化**：「一定」「必然」「百分百」「所有人」→ 换成带范围和口径的表述。
3. **不承诺**：收益、效果、通过率、治愈率不做承诺式表述；健康 / 法律 / 金融选题
   必须有风险提示意识（「具体请咨询专业人士」类收尾）。
4. **不冒充**：不冒充权威机构口吻，不暗示官方背书。
5. **不代做**：涉及作业、论文、考试的内容只讲方法与合规工具，不代写代考。
6. **平台规则**：不引导站外违规交易，不用极限词（广告法口径：最高级、国家级、绝对有效）。

## 3. 口播稿硬约定（S5，TTS 相关，违反必返工）

1. **数字一律中文读法**：
   - `4.3%` → 「百分之四点三」；`2026 年` → 「二零二六年」；`20MB` → 「二十兆」
   - 分数、小数、年份、单位全部展开，否则 TTS 读破。
2. **英文缩写先试听 3 秒样本**：MD5 / AI / ARIMA / XGBoost 在云希男声下各有读法，
   不行就改中文说法（MD5 → 「M D 五」）。
3. **经验口径加软化词**（「大约」「通常」）；事实类已过 S3，直接说。
4. **长句拆短**：口播句超过 25 字尽量拆，评委观众都靠听觉，书面长句听不清。

## 4. 字数预算（时长控制）

- 中文长句多：**5.6 字/秒**；短句多：**6.5 字/秒**
- RATE 修正：+20% 时按基准表；**+28% 时字数上限再乘 1.06**
- 超时长的顺序：**先压稿 7% → 再提 rate**。别只加 rate，会挤到听不清。

## 5. 钩子设计（前 15 秒）

- **三连数字**优先：数字用**有出处的**，不用经验口径（「三个数字，决定你能不能……」）。
- 反直觉断言 + 一句悬念；不铺背景，第一句进冲突。
- 钩子里的数字必须和正文的场景、封面的文案对得上（三处一致）。

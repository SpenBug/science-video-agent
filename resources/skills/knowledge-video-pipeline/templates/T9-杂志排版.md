# T9 · 杂志排版档（Magazine）

> **唯一一档「靠排版不靠动效」。** 纯白底 + 超大衬线标题 + 细分割线 + 多栏正文 + 首字下沉 + 唯一强调色正红，像杂志内页。
> 状态：✅ 端到端已验证（真配音 + 真渲染 + 后处理两关全过）· ⚠️ 未适配竖版、无封面

## 1. 适用 / 不适用

| ✅ 适用 | ❌ 不适用 |
|---|---|
| 观点输出（"我认为…"） | 数据展示（→ T8） |
| 方法论沉淀、行业观察 | 知识点罗列（→ T7） |
| 系列开篇 / 收尾 | N 条清单（→ T2） |
| 需要「高级感」的品牌向内容 | 紧迫场景（→ T2） |

**判断**：这一期的价值在**一句话主张**而不是一堆信息 → 用本档。

## 3. 风格 DNA

### 3.1 色板

| 角色 | 值 | 用途 |
|---|---|---|
| `WHITE` | `#FFFFFF` | 主底（纯白，本档不要暖白） |
| `OFFWHITE` | `#F4F2ED` | 左侧竖色块（唯一的非白区域） |
| `INK` | `#111111` | 标题 / 细线（**纯黑，不是深灰**） |
| `GRAY` | `#4A4A4A` | 正文 |
| `FAINT` | `#9B9B9B` | 页眉页脚 / 标注 |
| `ACCENT` | `#E63946` | 唯一强调色（正红） |

**只有一个强调色**，这是本档和 T1 最大的区别。T1 是 8 色轮换，本档全片就一个红——正因为克制，才有杂志的质感。

### 3.2 字体

```
SERIF = "'Noto Serif SC','Songti SC','SimSun',serif"   // 标题 / 正文 / 引文
SANS  = "'PingFang SC','Microsoft YaHei','Noto Sans SC',sans-serif"  // 栏目名 / 页眉页脚 / 标签
```

- **标题**：宋体 900，字号极大（122px），`letterSpacing: -3`
- **正文**：宋体 400，25px，`lineHeight: 2`
- **引文**：宋体 **斜体**
- **标签**：黑体，小字号 + 大 `letterSpacing`（5–8）

### 3.3 背景两层

```
① backgroundColor: WHITE
② 左侧暖灰竖色块：#F4F2ED，宽 118px（从 0 展开）
```

**没有网格、没有光晕、没有渐变**。本档的层次完全靠排版（字号对比 + 细线 + 留白），加任何装饰都会掉档。

### 3.4 字号

| 元素 | 横版 |
|---|---|
| 栏目名（红，letterSpacing 8） | 21px / 600 |
| 大标题（宋体 900） | 122px / lineHeight 1.1 / letterSpacing -3 |
| 标题下红短线 | 168×2 |
| 导语（宋体） | 30px / lineHeight 1.85 |
| 正文（宋体） | 25px / lineHeight 2 |
| 首字下沉 | 92px / 900 / lineHeight 0.82 |
| 引文（宋体斜体） | 27px |
| 侧栏小标题（红） | 20px / 700 / letterSpacing 3 |
| 侧栏正文 | 21px |
| 页眉页脚 | 19px / letterSpacing 4–5 |

## 5. 动效语法

**本档是全六档里动效最少的。**

| 元素 | 动效 | 说明 |
|---|---|---|
| 所有文字 | 只做 opacity 淡入，**不做位移** | 杂志是「印出来的」，不是「飞进来的」 |
| 细线 / 下划线 | width 0→N，`transformOrigin: left` | 像印刷时线条延伸 |
| 首字下沉 | 跟正文一起淡入 | 不单独动 |
| 左侧色块 | width 0→118 | 整片唯一的「大动作」 |

```tsx
const fade = (start: number, dur = 20) =>
  interpolate(frame, [start, start + dur], [0, 1], { ...CLAMP, easing: EASE });
```

⚠️ **禁止位移、禁止缩放、禁止旋转**。本档的高级感来自克制，任何「弹一下」都会立刻变廉价。

## 6. 数据层

```ts
export type Spread = {
  section: string;      // 栏目名，如「方法论」
  title: string;        // 大标题，用 <br /> 控制断行（排版就是内容）
  accentWord?: string;  // 标题里染成红色的词
  lead: string;         // 导语（左栏）
  columns: string[][];  // 正文段落数组，每个元素是一栏
  quote?: { text: string; source: string };
  sidebar?: { n: string; d: string }[];  // 底部侧栏，3 项以内
  issue: string;        // 如「ISSUE 09」
  page: string;         // 如「PAGE 09」
};
```

**标题断行要手写**。杂志标题的换行位置是设计的一部分，交给自动换行会很难看。

## 7. 实现注意

### 7.1 右栏必须显式给 width（本档首轮渲染的致命 bug）

```tsx
// ✗ 右栏内容整个溢出画布右侧被裁掉
<AbsoluteFill style={{ left: 950, padding: "150px 96px 140px 0", flexDirection: "row" }}>

// ✓
<AbsoluteFill style={{ left: 950, width: 970, padding: "150px 96px 140px 0", flexDirection: "row" }}>
```

`AbsoluteFill` 自带 `width: 100%`，设了 `left` 之后宽度仍是 1920，于是从 950 画到 2870。

### 7.2 页眉也必须限高

```tsx
// ✗ 页眉跑到画布垂直中点 y≈540，压在标题上
<AbsoluteFill style={{ padding: "62px 96px 0 176px", flexDirection: "row", alignItems: "center" }}>

// ✓
<AbsoluteFill style={{ top: 0, height: 132, padding: "0 96px 0 176px", flexDirection: "row", alignItems: "center" }}>
```

详见 `references/gotchas.md` 第 19 / 20 条。

### 7.3 首字下沉用 CSS float

```tsx
<span style={{ float: "left", fontSize: 92, lineHeight: 0.82, marginRight: 12, marginTop: 6 }}>很</span>
```

`lineHeight` 要压到 0.82 左右，否则下沉字会撑高首行。`marginTop` 微调基线对齐。

### 7.4 留白是设计，不是没填满

右栏正文结束到侧栏之间会有 300px 左右空白。**这是刻意的**——左栏的大标题高度会补上视觉重量。不要为了「填满」而加内容。

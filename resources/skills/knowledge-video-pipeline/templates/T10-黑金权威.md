# T10 · 黑金权威档（Black & Gold）

> **唯一一档「有官方压迫感」。** 近黑底 + 金色细线 + 象牙白衬线 + 金色印章，像正式文件或颁奖典礼。
> 状态：✅ 端到端已验证（真配音 + 真渲染 + 后处理两关全过）· ⚠️ 未适配竖版、无封面

## 1. 适用 / 不适用

| ✅ 适用 | ❌ 不适用 |

## 3. 风格 DNA

### 3.1 色板

| 角色 | 值 | 用途 |
|---|---|---|
| `BG` | `#0B0B0D` | 主底（近黑，**不是纯黑**） |
| `BG2` | `#121114` | 渐变中段（带一点暖，衬金） |
| `GOLD` | `#C9A227` | 金（主） |
| `GOLD_LIGHT` | `#E8C55F` | 亮金（标题强调） |
| `GOLD_DIM` | `rgba(201,162,39,0.34)` | 金线（主边框） |
| `GOLD_FAINT` | `rgba(201,162,39,0.14)` | 金线（次级 / 条款分隔） |
| `IVORY` | `#F5F1E8` | 象牙白（正文，**不用纯白**） |
| `DIM` | `#8A8578` | 次要文字（带金味儿的灰） |

**关键：所有「白」都要偏暖（象牙白），所有「灰」都要偏金。** 冷白配金色会显廉价。

### 3.2 字体

```
SERIF = "'Noto Serif SC','Songti SC','SimSun',serif"   // 标题 / 编号
SANS  = "'PingFang SC','Microsoft YaHei','Noto Sans SC',sans-serif"  // 条款正文
```

- **标题**：宋体 900，96px，`letterSpacing: 6`（**字距要拉开，这是权威感的主要来源**）
- **条款编号**：宋体 900，40px，金色
- **条款标题**：黑体 700，34px
- **条款说明**：黑体 400，25px，`DIM` 色

### 3.3 背景三层

```
① backgroundColor: BG
② linear-gradient(150deg, BG2 → BG → #08080A)
③ 单一径向光晕：radial-gradient(900px 620px at 76% 34%, rgba(201,162,39,0.10), transparent 64%)
```

### 3.4 金色内边框（本档的招牌）

```
① 外框：inset 44，1px GOLD_DIM
② 内框：inset 54，1px GOLD_FAINT
③ 四角标记：26×26，2px 金色 L 形，分别 rotate 0 / 90 / -90 / 180
```

双层细框 + 四角标记 = 「正式文件」的视觉符号。**这三样缺一不可**，只画一层框会像普通的描边卡片。

### 3.5 字号

| 元素 | 横版 |
|---|---|
| 页眉标签（金，letterSpacing 7） | 20px |
| 页眉右侧（DIM，letterSpacing 4） | 20px |
| 大标题（宋体 900） | 96px / lineHeight 1.24 / letterSpacing 6 |
| 标题下金线 | 320×2 渐变 |
| 条款编号（宋体 900） | 40px |
| 条款标题 | 34px / 700 |
| 条款说明 | 25px |
| 印章中心字（宋体 900） | 104px |

## 5. 动效语法

**本档的动效要「庄重」：慢、稳、有落定感。**

| 元素 | 动效 | 说明 |
|---|---|---|
| 页眉金线 | `scaleX` 0→1，`transformOrigin: left` | 从中间向两侧展开 |
| 标题 | 淡入（不位移） | 权威内容不「飞」 |
| 标题下金线 | width 0→320 渐变 | |
| 条款 | 逐条淡入 + translateY 16→0 | 三条间隔 12 帧，节奏要慢 |
| **金印** | `scale 1.35→1` + `rotate -22°→0`，缓动用 `cubic-bezier(0.2, 1.4, 0.4, 1)` | **「盖章落定」的感觉**，带一点过冲回弹 |
| 虚线环 | 持续旋转 `frame * 0.35` | 唯一的持续动效，很慢 |

```tsx
const sealP = interpolate(frame, [30, 68], [0, 1], {
  ...CLAMP, easing: Easing.bezier(0.2, 1.4, 0.4, 1),   // 过冲，才有「啪」一下盖下去的感觉
});
const sealScale = 1.35 - 0.35 * sealP;
const sealRot = (1 - sealP) * -22;
```

## 7. 实现注意

### 7.1 页眉必须限高（本档首轮渲染的 bug）

```tsx
// ✗ 页眉跑到画布垂直中点，和金印重叠
<AbsoluteFill style={{ padding: "96px 130px 0", flexDirection: "row", alignItems: "center", gap: 24 }}>

// ✓
<AbsoluteFill style={{ top: 0, height: 150, padding: "0 130px", flexDirection: "row", alignItems: "center", gap: 24 }}>
```

详见 `references/gotchas.md` 第 19 / 20 条。

### 7.2 四角标记的旋转

```tsx
{[
  { top: 44, left: 44 },     // rotate(0)
  { top: 44, right: 44 },    // rotate(90)
  { bottom: 44, left: 44 },  // rotate(-90)
  { bottom: 44, right: 44 }, // rotate(180)
].map((pos, i) => (
  <div style={{
    position: "absolute", width: 26, height: 26,
    borderTop: `2px solid ${GOLD}`, borderLeft: `2px solid ${GOLD}`,
    transform: `rotate(${[0, 90, -90, 180][i]}deg)`, ...pos,
  }} />
))}
```

只画 `borderTop` + `borderLeft`（一个 ⌐ 形），靠旋转摆到四个角。**别用四个方向的 border 组合**，那样转起来会错位。

### 7.3 条款贴底用 `justifyContent: flex-end`

条款区的 `AbsoluteFill` 不设 `top`（保持全高），用 `justifyContent: "flex-end"` + `paddingBottom` 让内容贴底。这样条款数量变化时不用改坐标。

### 7.4 金印不要压到正文

印章位置 `right: 150, top: 330`，尺寸 300×300 → 占 x=1470~1770、y=330~630。
标题区宽度限在 1240（`padding-right` 留出空档），条款区文字最长到 x≈1000。**互不干扰**。改标题长度或加条款时，先确认没侵占印章的方框。

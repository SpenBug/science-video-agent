## 一、封面规格

### 1.1 两个尺寸（**别再写错**）

| 名称 | 尺寸 | 平台 | 交付包里的文件名 |
|---|---|---|---|
| 4:3 | **1200×900** | B 站 / YouTube | `封面4比3.png` |
| 3:4 | **1080×1440** | 小红书 / 抖音 / 快手 | `封面3比4.png` |

⚠️ 历史事故：交付包 README 里一度写的是 1600×900 / 1080×1920，**那是错的**。以实物为准。

⚠️ **2026-09-21 修**：上面 4:3 那行的文件名原先误写成 `封面16x9.png`（尺寸栏明明写着 1200×900，命名自相矛盾），照着做会**误出一张 1920×1080 的 16:9 封面**——本次华为杯模板期就踩了这个坑。**封面只出 4:3 与 3:4 两种，不出 16:9。**

### 1.2 封面铁律

**封面必须复用视频里的 hook 数字 / 清单条目**，保证缩略图上的数字和片头对得上。
观众划到时如果发现是两张片子，完播率会掉。

| 档 | 封面必须复用的内容 |
|---|---|
| T1 | hook 的三连数字（如 30 / 5 / 7） |
| T2 | 清单条目数组（ITEMS），2 列网格逐条列 |
| T3 | 钩子的硬约束数字（如 1 个 MD5 / 20MB / 60%） |
| T4 | 主论文图 / 题目原图 |
| T5 | 最抓人的那个数字（截止天数 / 最高奖金） |

### 1.3 T1 封面结构（默认版式）

```
① 顶部标签行：黄底深字胶囊「数模真题拆解 ⑫」+ 灰字副标
② 三连数字卡：128px 宋体 900，各带 1px 语义色描边
③ 主标题 84~96px 宋体 900 + 110×7 红→黄渐变短下划线 + 两行灰字副标
④ 要点胶囊行：ROUTE 前 4 项 + 「等 7 处」
⑤ 顶部 10px 红→黄→青渐变条 + 底部 10px 青→黄→红渐变条（镜像）
```

### 1.4 T2 封面结构（网格版式，与 T1 完全不同）

```
① 顶部标签：红圆点 + amber 字「开赛前 · 最后几小时」（letterSpacing 7）
② 超大主标题 168px(竖) / 132px(横)，900 字重，letterSpacing -4
③ amber 副标题 46/36px
④ 8 项 2 列网格：每格 = amber 编号 01-08 + 文字，玻璃底 + 细描边
⑤ 右下角角标
```

⚠️ `风格规范\template\` 里**只有 T1 风格的 `EpisodeCover.tsx`**，没有 T2 的网格封面。
要用 T2 封面就照 `特别期_开赛前8小时\项目源码\mcm-video-temp\src\remotion\EpisodeExtraCover.tsx` 加一个变体。

### 1.5 封面文案改哪里

```ts
export const BRAND = { corner: "数模真题拆解 · 第 N 期" };   // 右上角标
export const COVER = { tag, tagSub, title, sub, chips, chipsTail };  // 封面文案
```

### 1.6 渲染命令

```powershell
npx remotion still src\remotion\index.ts Cover43 out\封面4比3.png     # 1200×900
npx remotion still src\remotion\index.ts Cover34 out\封面3比4.png     # 1080×1440
```
`--gl=angle` 对 still 意义不大，可不带。

## 二、竖版适配

### 2.1 先问：要不要出竖版？

**用户 2026-09-10 拍板：默认不出竖版。**（见 `D:\自媒体\自媒体\MEMORY.md`）
S11 渲染前必须向用户确认一次，不要默认渲染两个版本。

### 2.2 竖版字号缩放

```ts
const fontK = isPortrait ? (width/1080)*0.94 : width/1920;
// 标题 60*fontK / 正文 28*fontK / 标签 22*fontK
```

### 2.3 竖版适配清单（逐项过）

| # | 检查项 | 常见问题 | 修法 |
|---|---|---|---|
| 1 | 左右分栏 | 挤成一团 | 改 `flexDirection: column` 堆叠 |
| 2 | 正文区垂直位置 | **底部大片留白** | `justifyContent` 改 `center`（第十三期 redline/cards 就是这么修的） |
| 3 | 大数字 | 撞边 | T2：340px → 300px；T4：按 34% 宽度重算 |
| 4 | 字幕字号 | 太小看不清 | T1：横版 38 → 竖版 **46**；T2：横版 44 → 竖版 40 |
| 5 | 双栏对比（compare） | 两栏都太窄 | 竖版改上下堆叠 |
| 6 | 箭头方向 | `→` 在窄屏不合理 | 改 `↓` |
| 7 | 网格 / 光晕位置 | 居中偏上更好看 | T2 的径向光晕改 `at 50% 30%` |
| 8 | 清单条目 | 太多放不下 | 竖版减到 6 条以内，或分两屏 |

### 2.4 竖版抽帧 QA

竖版容易在**中段和片尾**出问题，抽这三个位置：
- 10% 片头
- 中段最密的那个场景
- 片尾

渲染 probe 帧时渲染日志的 `overflow` 必须为 0。

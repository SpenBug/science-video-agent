## 1. 适用 / 不适用

| ✅ 适用 | ❌ 不适用 |
|---|---|
| 结果检验（误差、残差、拟合优度） | 观点输出（→ T9） |
| 灵敏度分析（参数扰动的影响幅度） | 知识点讲解（→ T7） |

| 收敛过程、迭代次数 | 长文叙述（→ T1） |

**判断**：这一场景的核心是**数字**还是**句子**？数字为主 → 用本档。

## 3. 风格 DNA

### 3.1 色板

| 角色 | 值 | 用途 |
|---|---|---|
| `BG0` | `#0A1628` | 主底（深海军蓝，**不是纯黑**） |
| `BG1` | `#061020` | 渐变收尾 |
| `CYAN` | `#00E5FF` | 主色 / 网格 / 中性数据 |
| `GREEN` | `#39FF88` | 达标 / 良好 |
| `AMBER` | `#FF9F1C` | 警告 / 临界 |
| `RED` | `#FF4D6D` | 超标 / 异常 |
| `TEXT` | `#E6F4FF` | 主文字 |
| `DIM` | `#7A93B0` | 次要文字 |
| `FAINT` | `#44576E` | 未激活的刻度 / 最弱文字 |
| `PANEL` | `rgba(0,229,255,0.045)` | 面板底 |
| `LINE` | `rgba(0,229,255,0.16)` | 面板描边 |

**语义色按「健康度」分配**，不是按顺序轮换：达标绿、临界琥珀、超标红。观众扫一眼就知道哪项有问题。

### 3.2 字体

```
SANS = "'PingFang SC','Microsoft YaHei','Noto Sans SC',sans-serif"     // 标签 / 标题
MONO = "'JetBrains Mono','Cascadia Mono','Consolas','Courier New',monospace"  // ★ 所有数字
```

⚠️ **所有数字必须用等宽字体**。这是这套的灵魂——等宽数字才有「仪表读数」的感觉，比例字体会让数字跳动时宽度不稳。

### 3.3 背景四层

```
① backgroundColor: BG0
② linear-gradient(160deg, BG0 → BG1)
③ 32px 精密网格：rgba(0,229,255,0.045)   ← 比 T1 的 52px 更密
④ 单一径向光晕：radial-gradient(1100px 700px at 78% 6%, rgba(0,229,255,0.10), transparent 62%)
```

## 5. 三个核心组件

### 5.1 环形仪表（Ring）

```tsx
const R = 62, C = 2 * Math.PI * R;
// 外圈：40 根刻度线，已激活的用语义色、未激活的用 FAINT
// 内圈：进度弧，strokeDasharray={C} strokeDashoffset={C * (1 - v)}
//        transform="rotate(-90 84 84)" 让弧从 12 点方向开始
// 中心：等宽数字，做 count-up
```

**刻度线比纯圆弧更有仪表感**。每 5 根加粗一根（`i % 5 === 0`）作为主刻度。

### 5.2 横向对比条（Bars）

```tsx
<div style={{ height: 12, background: "rgba(0,229,255,0.07)", borderRadius: 6 }}>
  <div style={{ width: `${w*100}%`, background: b.color, borderRadius: 6 }} />
</div>
```

轨道底色用 7% 透明度的主色，比灰色轨道更协调。**右侧必须给数值**，且数值跟着条一起从 0 涨上去。

### 5.3 收敛曲线（Sparkline）

```tsx
<polyline
  points={pts}
  pathLength={1}
  strokeDasharray={1}
  strokeDashoffset={1 - sparkP}   // 逐段绘制
/>
// 数据点：sparkP 覆盖到的点才亮，形成「画到哪亮到哪」的效果
```

`pathLength={1}` 把路径总长归一化成 1，`strokeDashoffset` 就能直接用 0→1 的进度控制，不用算真实长度。

## 6. 数据层

```ts
type Metric = {
  label: string;   // 指标名
  value: number;   // 当前值
  max: number;     // 量程上限（决定弧长比例）
  unit: string;    // 单位或量程说明，如 "%" / "0 – 1"
  dec: number;     // 小数位数 ← 必须有，否则 3.6 会显示成 3.600
  color: string;
  note: string;    // 数据来源，如「留出验证」
};

const BARS = [{ name: string; v: number; color: string }];  // v 是相对值，0–1
const SPARK = [number];  // 0–1 之间的序列
```

⚠️ **`dec` 这个字段不能省**。我第一版忘了，结果百分比显示成 `3.600`、单位栏还漏出个 `—`。数值格式必须显式声明。

## 7. 实现注意

### 7.1 顶栏和底部面板必须限高

`AbsoluteFill` 自带 `height: 100%`，所以：

```tsx
// ✗ 顶栏内容被拉到画布垂直中点（y≈540），压在环形指标上
<AbsoluteFill style={{ padding: "52px 84px 0", flexDirection: "row", alignItems: "center" }}>

// ✓
<AbsoluteFill style={{ top: 0, height: 150, padding: "0 84px", flexDirection: "row", alignItems: "center" }}>

// ✗ 底部面板被推到画布外（y=500 起、高 1080）
<AbsoluteFill style={{ top: 500, padding: "0 84px" }}>

// ✓
<AbsoluteFill style={{ top: 500, height: 540, padding: "0 84px" }}>
```

详见 `references/gotchas.md` 第 19 / 20 条。**本档首轮渲染三处踩了两处。**

### 7.2 count-up 用 `interpolate` 而不是 `setState`

Remotion 里不要用 React state 做动画。数值直接由帧算：

```tsx
const shown = interpolate(frame, [delay, delay + 40], [0, m.value], { ...CLAMP, easing: EASE });
```

这样 seek 到任意帧都能得到正确画面（预览、抽帧、渲染三处一致）。

### 7.3 等宽数字的 letterSpacing

`MONO` 字体下加 `letterSpacing: -1` 让大数字更紧凑；单位行反而要 `letterSpacing: 1` 拉开一点。同一套字体，两种处理。

# T7 · 纸感笔记档（Paper Note）

> **唯一一档「非屏幕」质感。** 米白纸 + 装订线 + 衬线正文 + 荧光笔高亮 + 楷体批注，像一本摊开的精装笔记本。
> 状态：✅ 端到端已验证（真配音 + 真渲染 + 后处理两关全过）· ⚠️ 未适配竖版、无封面
> 源码：`templates/code/src/remotion/T7PaperNote.tsx`（单页演示）<br>`templates/code/src/remotion/T7PaperNoteVideo.tsx`（完整视频组件）　预览：`assets/preview/T7-纸感笔记.png`

## 1. 适用 / 不适用

| ✅ 适用 | ❌ 不适用 |
|---|---|
| 知识点讲解（定义、性质、判据） | 数据结果展示（→ T8） |
| 公式推导与逐步高亮 | N 条紧迫清单（→ T2） |
| 复盘笔记、易错点批注 | 赛事资讯（→ T5） |
| 想要「不那么像 PPT」的亲和感 | 长文观点输出（→ T9） |

**判断**：内容像「我记在笔记本上的一页」→ 用本档。像「我讲给观众听的一段」→ 用 T1。

## 3. 风格 DNA

### 3.1 色板

| 角色 | 值 | 用途 |
|---|---|---|
| `PAPER` | `#FAF7F0` | 纸底（不是纯白，偏暖） |
| `INK` | `#1F1D1A` | 标题 / 主墨色 |
| `INK_SOFT` | `#5C5750` | 正文（比主墨浅一档） |
| `INK_FAINT` | `#A8A29A` | 页眉页脚 |
| `RULE` | `rgba(31,29,26,0.045)` | 36px 方格 |
| `BIND` | `rgba(31,29,26,0.22)` | 装订线 |
| `HILITE` | `#FFE066` | 荧光笔黄 |
| `RED` | `#C8402F` | 批注红（不用正红，偏砖红更像红笔） |

**只有两个强调色**：荧光笔黄（正文高亮）+ 砖红（批注 / 小标题）。多一个都会破坏「手写笔记」的朴素感。

### 3.2 字体（本档的灵魂）

```
SERIF = "'Noto Serif SC','Songti SC','SimSun',serif"          // 标题 + 正文
SANS  = "'PingFang SC','Microsoft YaHei','Noto Sans SC',sans-serif"  // 标签 / 页眉页脚
KAI   = "'Kaiti SC','STKaiti','KaiTi','楷体',serif"             // ★ 批注
```

⚠️ **楷体是这套的灵魂**。批注用楷体、正文用宋体，两者对比才有「正文是印的、批注是我写的」的层次。如果环境没有楷体，回退到宋体会丢失这个效果——**发布前一定要目检批注那一段的字体**。

### 3.3 背景三层

```
① backgroundColor: PAPER (#FAF7F0)
② 36px 方格：双 linear-gradient 1px 线，RULE
③ 装订线：x=132 一条 1.5px BIND，x=138 一条 1px 更淡的线（双线更像本子）
```

### 3.4 字号

| 元素 | 横版 |
|---|---|
| 栏目名（砖红，letterSpacing 6） | 22px / 600 |
| 大标题（宋体 900） | 78px / lineHeight 1.22 |
| 标题下划线 | 140×3，从 0 展开 |
| 正文（宋体） | 33px / lineHeight 2 |
| 楷体批注 | 27px / lineHeight 1.75 |
| 本页要点标题 | 20px / 700 / letterSpacing 4 |
| 本页要点条目（宋体） | 27px |
| 页眉页脚 | 21px |

## 5. 动效语法

**本档的动效要「像写上去」，不要「像弹出来」。**

| 元素 | 动效 | 说明 |
|---|---|---|
| 栏目名 / 标题 / 正文 | `fadeUp(frame, start)` = opacity 0→1 + translateY 14→0 | 位移很小，别超过 20px |
| 标题下划线 | width 0→140 | 像用尺子画出来 |
| 荧光笔高亮 | `clipPath: inset(0 X% 0 0)`，X 从 100→0 | **从左往右扫**，这是荧光笔的方向 |
| 楷体批注 | 引线 `strokeDashoffset` 300→0 + 卡片淡入 | 先画线，再出字 |
| 便签纸 | 最后出现（frame 62+） | 像读完才贴上去 |

```tsx
const fadeUp = (frame: number, start: number, dur = 16) => {
  const p = interpolate(frame, [start, start + dur], [0, 1], { ...CLAMP, easing: EASE });
  return { opacity: p, transform: `translateY(${(1 - p) * 14}px)` };
};
```

⚠️ **本档不要用缩放（scale）**。纸上的字不会放大出现，一缩放就出戏。

## 6. 数据层

单页配置（每场景一条）：

```ts
export type NotePage = {
  section: string;      // 栏目名，如「灵敏度分析」
  title: string;        // 大标题，支持 <br /> 换行
  body: string[];       // 正文段落
  highlight: { text: string; paraIndex: number };  // 荧光笔高亮的词 + 在第几段
  margin?: string;      // 楷体批注，没有就不显示批注栏
  marginTag?: string;   // 批注标签，默认「批注 · 易错点」
  points?: string[];    // 便签「本页要点」，2 条以内
  date: string;
  page: string;         // 页码，如「第 07 页」
};
```

## 7. 实现注意

### 7.1 `AbsoluteFill` 的两个陷阱（本档也踩过）

```tsx
// ✗ 设了 left 不给 width → 溢出画布
<AbsoluteFill style={{ left: 1400, top: 300 }}>
// ✓
<AbsoluteFill style={{ left: 1400, top: 300, width: 400 }}>
```

```tsx
// ✗ 全高容器 + alignItems:center → 内容被拉到画布垂直中点
<AbsoluteFill style={{ padding: "46px 96px 0 0", flexDirection: "row" }}>
// ✓ 本档页眉用 justifyContent:flex-end，不设 alignItems，天然顶部对齐
```

详见 `references/gotchas.md` 第 19 / 20 条。

### 7.2 便签纸靠 `marginTop: "auto"` 贴底

正文区是列方向 flex，便签加 `marginTop: "auto"` 就会被推到 padding 底部。不用算绝对坐标。

### 7.3 高亮的定位

荧光笔块用 `position: absolute` 套在 `position: relative` 的 inline-block 外层上，`top: 4, bottom: 6` 让黄条只盖住文字高度的 80%，比满高更像真荧光笔。

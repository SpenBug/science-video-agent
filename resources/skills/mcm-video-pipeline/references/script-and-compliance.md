# 口播稿规则与合规红线（S3 / S5 用）

---

## 一、口播稿三条硬约定

### 1. 数字一律中文读法
| 别写 | 写成 |
|---|---|
| `4.3%` | 百分之四点三 |
| `2026 年` | 二零二六年 |
| `20MB` | 二十兆 |
| `60%` | 百分之六十 |
| `123h` | 一百二十三小时 |
| `±20%` | 正负百分之二十 |

TTS 会把 `4.3%` 读成「四、三、百分号」，或直接念错。

### 2. 英文缩写先试听
`MD5 / PDF / AI / RAR / ZIP / ARIMA / XGBoost / AIC / BIC / Robin / Fo` 在云希男声下各有读法。
**做法**：先跑 3 秒样本听一遍；不行就改中文说法（`MD5` → 「M D 五」，`Robin` → 「罗宾边界」）。

### 3. 经验口径加软化词
- 评委只看 5 分钟 → 「评委通常只看大约五分钟」
- 30 页论文 → 「大约三十页」
- 规则类内容先对官方原文（见第三节）

## 二、字数预算

| 档 | 时长 | 口播字数 | 字速 |
|---|---|---|---|
| 短平快（T2） | 110–120s | 620–700 字 | 5.6–6.5 字/秒 |
| 系列标准（T1/T5） | 185–195s | 1180–1230 字 | 5.6 字/秒（长句多）/ 6.5（短句多） |
| 长拆解（T3/T4） | 240–320s | 1500–2000 字 | 5.6 字/秒 |

**超时处理顺序（不能颠倒）**：
1. 先精简约 7% 文案（砍重复的承接句、合并同类清单项）
2. 再把 `RATE` 从 `+20%` 提到 `+28%`
3. 两步都不够 → 回 S4 砍场景

实测参考：
- 第十三期：初稿 1410 字 → 实测 217.8s（目标 185–195）→ 压到约 1040 字 → 落地 185.28s
- 第十二期：初稿 +20% 实测 221s（目标 190s）→ 精简约 7% + rate 提到 +28% → 189.65s
- 特别期A：rate +20%（密读降档），286.37s
- 奶油风真题（T4）：rate **+8%**（慢速讲解），242.15s / 30 句

## 三、口径分级（写稿时逐句标注）

| 级别 | 定义 | 口播写法 |
|---|---|---|
| **题面事实** | 题目/规则原文写死的 | 可以直接说死（「题目给的是二十五厘米」） |
| **本队实算结果** | 自己跑出来的数字 | **必须带**「大约」「实算出来」，不承诺普适 |
| **经验口径** | 行业惯例、往年观察 | **必须带**「通常」「大概」，不当硬规定讲 |
| **官方处罚条款** | 规则里的罚则 | **逐字对原文**，不加强、不外推 |

---

## 四、合规红线

1. **不代写代做。** 视频定位是「教学复盘 / 讲思路」，只讲方法和真实结果量级，不提供可直接提交的完整论文成品。
2. **不承诺获奖。** 不说「这样写就能拿国奖」。
3. **不编造官方条款。** 官方没写的处罚口径不许说；不确定的用「以你所在赛区通知为准」收口。
4. **规则类内容必查原文。** 工作区有 `mcm_rules_extracted.txt`（国赛规则摘录）；涉及当年规则要联网核实官方最新文件。
5. **发布文案也要过红线。** 文案里同样不能出现「代做」「保奖」类表述，结尾建议带一句「今年规则以你所在赛区的通知为准」。

## 五、发布文案结构（S13 用）

```markdown
# <期数> · 发布文案（定稿）

主题：<一句话>
时长：X 分 XX 秒（XXX 秒）

## 一、标题（三选一，按平台挑）
> 全部控制在 30 字以内（含标点和字母，按字符计）
1. <主推标题>（XX 字）
2. <备选>（XX 字）
3. <备选>（XX 字）
> 推荐：B 站用 1，小红书 / 抖音用 2，公众号用 3。

## 二、简介 / 正文
<可直接复制粘贴的正文，分点列出核心信息>

## 三、章节时间戳（B 站 / YouTube 直接粘）
00:00 <场景标题>
00:15 <场景标题>
...

## 四、标签
<主标签，顿号分隔>
小红书补充：<补充标签>

## 五、封面与置顶评论
封面用 3:4（1080×1440），主标题「<封面主标题>」，三连数字 X / Y / Z。
置顶评论建议：
> <清单式评论，方便观众截图>
```

**标题要求**：关键词顶在开头（如「数模国赛」「华为杯」），搜索和推荐能进对池子；30 字以内；数字型 / 痛点型 / 反差型各出一条。
**章节时间戳必须从 `timing.json` 的真实 `start_sec` 换算**，不要手估。

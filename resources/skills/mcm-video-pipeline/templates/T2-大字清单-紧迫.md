# T2 · 大字清单（紧迫档）

> **扫读最快的一档。** 单版式 + 空心大数字 + 三档语气配色，专治「N 条清单 / 考前急救 / 紧迫 CTA」。
> 真源：`特别期_开赛前8小时\项目源码\mcm-video-temp\`

---

## 1. 适用 / 不适用

| ✅ 适用 | ❌ 不适用 |
|---|---|
| N 条清单盘点（「8 件事」「7 条红线」） | 方法对比 / 推导（→ T1） |
| 考前 / 开赛前 / 截止前急救 | 一道真题完整求解（→ T3） |
| 紧迫 CTA、预警 | 论文图讲解（→ T4） |
| 时长 < 2 分钟、要点 ≤ 10 条 | 赛事资讯（→ T5） |

**判断**：内容能不能用「编号 + 一句话」表达？**能，且条数 ≤ 10** → 用本档。

---

## 2. 规格

| 项 | 值 |
|---|---|
| 时长 | 110–120s（实测 111.51s） |
| 场景数 | 8–10（实测 10） |
| 口播字数 | 620–700 字 |
| rate | `+20%` 基准 / `+30%` 紧迫感更强（开赛前8小时用 +30%） |
| 音色 | `zh-CN-YunxiNeural` |
| GAP | **0.35s**（段间静默，让旧场景自然淡出） |
| fps | 30 |
| 帧数 | 约 3345 |
| 输出 | 横版 + 竖版 + **网格封面**（与 T1 封面完全不同） |
| 字幕 | **整段模式**（不做句级分段） |

## 3. 风格 DNA

### 3.1 色板（`epExtra_data.ts` 的 `COLORS`）

```ts
export const COLORS = {
  bg: "#070B18",        // 主底（与 T1 的 bg0 相同）
  bg2: "#0D1428",       // 渐变中段
  bg3: "#05070F",       // 渐变收尾（更黑，紧迫感来源）
  text: "#F4F7FF",
  dim: "#8A97B8",
  line: "rgba(255,255,255,0.10)",   // 比 T1 的 0.13 更淡
  amber: "#FFB020",     // 强调 / warn
  red:   "#FF3B5C",     // danger
  cyan:  "#22D3EE",     // normal
};
```

### 3.2 三档语气系统（**本档核心，T1 没有**）

| tone | 颜色 | 含义 | 实测用法 |
|---|---|---|---|
| `normal` | `#22D3EE` 青 | 常规信息 | hook |
| `warn` | `#FFB020` 琥珀 | 需要注意 | t1 / t3 / t4 / t6 / t8 |
| `danger` | `#FF3B5C` 红 | 必须做对 | t2 / t5 / t7 |

`TONE_COLOR[tone]` 一把决定 4 处：**径向光晕染色 / 顶部 6px 渐变条 / punch 句竖条 / 数字描边色**。
**换场景只换一个 `tone`，整片跟着变色**——比 T1 的 8 色 accent 更粗，但认知成本更低。

### 3.3 字体
```
SANS = "PingFang SC / Microsoft YaHei / Noto Sans SC / Source Han Sans SC"
```
⚠️ **本档不用宋体**，全部黑体，标题 900 字重 + `letterSpacing -3/-4`。

| 元素 | 横版 | 竖版 |
|---|---|---|
| 空心大数字 | 340px | 300px |
| 大标题 | 112px (800) | 92px (800) |
| 无 num 时的大标题 | 190px | 150px |
| punch 句 | 54px | 46px |
| 底部字幕 | 44px | 40px |
| kicker 标签 | 32px | 30px |

### 3.4 背景四层（与 T1 的差异用 ★ 标出）

```
① ★ 160° 三色渐变：#070B18 → #0D1428 → #05070F
② ★ 单一径向光晕：radial-gradient(circle at 30% 32%, accent22, transparent 62%)
   竖版改 at 50% 30%（居中偏上）
   ★ 呼吸动效：opacity = 0.55 + 0.35 * pulse，pulse = 0.5 + 0.5*sin(frame/22)
     背景在慢慢"呼吸"，制造紧迫感 —— 本档独有
③ ★ 64px 细网格（T1 是 52px），opacity 0.35
④ ★ 顶部 6px accent → transparent 70% 渐变条（T1 是顶底各 8px 全渐变）
⑤ 右上角角标「数模国赛 · 开赛前」
```

### 数据层结构（`epExtra_data.ts`，极简单场景 4 字段）
```ts
export type SectionCfg = {
  kicker: string;      // "赛前清单 04 / 08"
  num?: string;        // "04"，可选；没有就只显示超大标题
```

## 5. 场景与字幕机制（与 T1 不同）

**场景判定**：`if (sec >= sections[i].start_sec) idx = i` —— 取「起点已过的最后一个」。段间有 `GAP 0.35s` 静默，静默期旧场景自然淡出，不用额外处理。

**进出场用帧级（不是归一化 p）**：
```ts
enter = interpolate(frame, [sf, sf+9],          [0,1], clamp)
exit  = interpolate(frame, [sf+dfr-6, sf+dfr],  [1,0], clamp)
op    = enter * exit
// 位移：translateY(26 * (1 - slide))，slide = interpolate(p, [0,0.25], [1,0])
```

**字幕 = 整段显示**：底部一块 `VOICE_TEXTS[name]` 全文，不做句级分段。
> **清单类内容用整段**（一条 ≤ 2 句，读得快）；**长内容用句级分段**（防止一条字幕超过 3 行）。

## 7. 与 T1 的选用规则

| 内容形态 | 用哪档 | 理由 |
|---|---|---|
| 方法对比、错误 vs 正确、流程图、公式推导、评分细则 | T1 | 需要多版式承载密度 |
| N 条清单、考前急救、紧迫 CTA、「8 件事」式盘点 | **T2** | 大字 + 语气配色，扫读速度最快 |
| 时长 > 3 分钟、信息量大 | T1 | 单版式撑不住 |
| 时长 < 2 分钟、要点 ≤ 10 条 | **T2** | 单版式刚好 |

```powershell
python _gen_tts.py          # ① 配音体检 + 混音 + 回写 timing.json
python _check_sections.py   # 可选：只体检不改文件

npx remotion render src\remotion\index.ts ExtraPortrait  videos\ep-extra\portrait.mp4  --gl=angle
npx remotion still  src\remotion\index.ts ExtraCover34   videos\ep-extra\cover34.png
npx remotion still  src\remotion\index.ts ExtraCover43   videos\ep-extra\cover43.png
```

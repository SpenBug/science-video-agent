# T4 · 奶油论文图解档

> **唯一一档浅色风格。** 奶油底 + 左文右图，逐句讲论文截图 / 题目原图，轻量亲和。
> 真源：`_tools_pipeline\EpisodeScene.tsx` + `cumcm2021b-video`（2021 国赛乙醇制备 C4 烯烃）

---

## 1. 适用 / 不适用

| ✅ 适用 | ❌ 不适用 |
|---|---|
| 论文里的图 / 表逐张讲 | 深空风系列正片（→ T1） |
| 题目原图展示 + 讲解 | 紧迫清单（→ T2） |
| 想要「不那么严肃」的亲和感 | 一道真题完整求解（→ T3） |
| 时长 3–4 分钟 | 赛事资讯（→ T5） |

**判断**：主体是「论文里的图 / 题目原图」逐张讲 → 用本档。

---

## 2. 规格

| 项 | 值 |
|---|---|
| 时长 | 220–260s（实测 242.15s = 4:02） |
| 场景 | **6 章节**（open / q1 / q2 / q3 / q4 / end），**30 句** cue |

| 字幕 | 逐句条（每句一条字幕，句间 0.18s 间隙） |

## 4. 章节与字幕机制

### 4.1 章节边界硬编码（本档特有）
章节切分靠**句子索引**硬编码，不是从数据推导：
```python
SECTION_BOUNDARIES = {"open":0, "q1":9, "q2":14, "q3":20, "q4":25, "end":28}
SECTION_NAMES = ["open","q1","q2","q3","q4","end"]
```
⚠️ 改口播稿的句子数后，**必须同步改这两个常量**，否则章节标签错位。这是本档最容易踩的坑。

### 4.2 逐句字幕（本档核心）
每一行口播 = 一句 TTS = 一条字幕，逐句计时：
```python
gap = 0.18   # 句间静音间隙（秒），增强自然感
for i, (wav, ln) in enumerate(zip(wavs, lines)):
    d = dur(wav)
    cues.append({"idx":i, "text":ln, "start":round(t,3), "end":round(t+d,3), "duration":round(d,3)})
    t = d + gap
```
字幕条：句内进度 `localT` 驱动，淡入 + 上移 26px，`localT` 0→0.06 淡入、0.94→1 淡出。

### 4.3 图片动画（KenBurns，只在切图时触发）
```tsx
const imgKey = p.img;      // 图片作为动画触发键：仅当图片变化时重挂载
// 同图内多句不重放 —— 动画进度基于「图片首次出现后的累计时间」
const imgP   = clamp((t - CUES[firstIdx].start) / 3.5, 0, 1);
const imgZoom = interpolate(imgP, [0,1], [isOpen ? 1.02 : 1.05, isOpen ? 1.08 : 1.12], ...);
const imgFade = interpolate(imgP, [0,0.35], [0,1], ...);
const imgX    = interpolate(imgP, [0,1], ["3%","0%"], ...);
```

## 5. 数据层（displayPlan）

每句一条 `{ img, chapter, note }`：
- `img`：这一句展示哪张图（同图多句只播一次动画）
- `chapter`：左侧小节标题（宋体大字）
- `note`：本句要点卡正文

图素材放在工程 `public\`，组件里 `staticFile(p.img)` 引用。真源中的图命名参考：
`open_p1.png` / `open_p2.png`（原题）、`card_q1.png` / `lay_q1b.png` / `lay_q1c.png`（论文卡片图）、`verify_px.png` / `verify_constraint.png`（验算图）。

## 6. 执行清单

本档的脚本链路与深空档**不同**（是逐句手工拼接，不是 `_gen_tts.py`）：

```powershell
# 用已装 edge-tts 的解释器跑（APP 内置环境已预装；自装环境先 pip install edge-tts）
# ① 逐句 TTS：每行一句 → 各自合成 → 测时长 → 拼接 → 精确 SRT + timing.json
python gen_tts_sentence.py
# ② 若已有 part wav（_tts_parts\part_NN.wav），只重拼音轨
python _stitch_wav.py
# ③ 同步校验
python check_sync.py
python _final_check.py
# ④ 渲染
npx remotion render src\remotion\index.ts <Id> <ep>_无BGM.mp4 --gl=angle
# ⑤ 手工混 BGM（本档没有 --mix 参数，用 ffmpeg amix，BGM 0.10）
```

**关键参数**（`gen_tts_sentence.py` 顶部改）：

## 9. 2026-09-21 实测：已重写为动态组件（不再硬编码）

**背景**：上面第 8 节的警告——「`SECTION_BOUNDARIES` 硬编码，复用时改动成本最高」——在华为杯模板分享这期（280.40s）里解决掉了。

**新组件**（已入库 `templates/code/src/remotion/`）：

| 文件 | 作用 |
|---|---|
| `T4CreamPaperVideo.tsx` | 完整视频组件，从 `timing.json` 的 `sections[]` 自动定位场景与句子 |
| `T4plan.example.ts` | 场景计划示例（复制成 `plan.ts` 用） |
| `T4RepoTree.tsx` | 附属版式：文件树（`mode: "tree"`） |
| `T4YearTable.tsx` | 附属版式：左右对比表（`mode: "year"`） |

**相比原 `_tools_pipeline/EpisodeScene.tsx` 的三处改进**：

1. **场景边界改为动态**：`sections[].start_sec` 直接来自 `timing.json`，改稿 / 改场景数都不用动组件。原来硬编码的 `SECTION_BOUND` 和 `CH_LABEL` 全部移到 `plan.ts`。
2. **图片按句轮换**：`plan.imgs[qi % plan.imgs.length]`，一个场景可绑多张图（本次 `cover` 绑 2 张、`table` 绑 3 张、`official` 绑 4 张），配合句级字幕自动切图。
3. **新增两种版式**：`tree`（文件树，讲仓库结构）和 `year`（左右对比表，讲「该改 vs 碰不得」）。

**本次实测参数与 T4 原始规格的差异（如实记录）**：

| 项 | T4 原规格 | 本次实测 | 原因 |
|---|---|---|---|
| 音色 | 云健 `YunjianNeural` | **云希 `YunxiNeural`** | 沿用第十三期已跑通配置 |
| rate | +8% | **+28%** | 1462 字要压进 250–280s |
| 时长 | 242.15s | **280.40s** | 内容量更大（10 场景 / 16 张页图） |
| 场景切分 | 句子索引硬编码 | **`timing.json` 驱动** | 本次改进 |

**工程复用**：`node_modules` 用 junction 指向已装好的期（`New-Item -ItemType Junction`），省掉 `npm install`。

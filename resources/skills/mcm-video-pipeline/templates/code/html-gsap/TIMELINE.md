## 二、断句修正说明（v1 关键改动）

**问题**：Kokoro 的 ONNX tokenizer 不认识中文全角标点（`。` `，` `、` `：` `！` 全部 tokenize 为空），
misaki 输出的停顿标记被丢弃，模型只保留句尾收束声调产生的停顿，听感是「整段连读」。

**修复**：分段合成管线（`tts_models/gen_tts_html.py`）：
1. 按标点切分文本为短句（保留标点）
2. 每句单独 g2p + ONNX 合成（语速 {{SPEED}}）
3. 裁剪每段首尾静音
4. 段间插入精确停顿：句号 0.45s / 冒号 0.30s / 逗号 0.18s / 顿号 0.15s

验证：测试句「今天，天气很好。评委看了摘要，决定生死。」从 2 处停顿（仅首尾）修复为 4 处自然停顿。

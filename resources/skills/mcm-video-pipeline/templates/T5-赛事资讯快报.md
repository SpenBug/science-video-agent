# T5 · 赛事资讯快报档

> **版式最多的一档（10 种）。** 赛程 / 报名 / 奖金 / 资格 这类「信息点密但每点都短」的资讯速报。
> 真源：`特别期_华为杯研赛资讯\项目源码\mcm-video-temp\`

---

## 1. 适用 / 不适用

| ✅ 适用 | ❌ 不适用 |
|---|---|
| 赛事资讯（赛程 / 报名 / 截止 / 结果） | 方法对比、推导（→ T1） |
| 奖金阶梯、奖项设置 | N 条紧迫清单（→ T2） |
| 参赛资格、组队规则、费用 | 真题求解（→ T3） |
| 横向对比（A 赛事 vs B 赛事） | 论文图讲解（→ T4） |
| 时长 180–200s，信息点 8–12 个 | 时长 < 2 分钟（→ T2） |

**判断**：主体是「赛事资讯」，每个信息点都很短但需要各自的可视化 → 用本档。

| 项 | 值 |
|---|---|
| 时长 | 180–200s（实测 186s = 3:06） |

## 3. 十种版式（本档核心资产）

| type | 版式 | 需要的数据字段 | 用途 |
|---|---|---|---|
| `countdown` | 倒计时 | `kicker` / `title` | 报名只剩 N 天 |
| `timeline` | 时间轴节点 | `date` / `time` / `event` / `accent` 数组 | 赛程关键节点 |
| `cards` | 信息卡（3 张） | `no` / `title` / `desc` / `accent` | 谁能报 / 怎么组队 / 多少钱 |
| `versus` | 横向对比双栏 | 对比项 | 华为杯 vs 本科国赛 |
| `ladder` | 奖金阶梯 | `name` / `detail` / `money` / `accent` | 奖项金额递增 |
| `gantt` | 甘特（双窗口） | `name` / `start` / `end` / `span` / `accent` / `warn?` | 两个截止窗口别搞混 |
| `alert` | 红线告警 | 三条禁令 | 违规直接取消资格 |
| `blocks` | 时间分配块 | `day` / `date` / `focus` / `pct` / `accent` | 四天怎么分 |
| `checklist` | 清单（复用 T1） | `checklist[]` | 开赛前 N 项准备 |
| `follow` | 关注引导 | `kicker` / `title` | 收尾 |

### 数据结构示例

```ts
export type Node = { date: string; time: string; event: string; accent: string };
// { date: "9/22", time: "08:00", event: "下载试题 ZIP 包，用官方 MD5 工具校验", accent: COLORS.red }

export type InfoCard = { no: string; title: string; desc: string; accent: string };

export type LadderStep = { name: string; detail: string; money: string; accent: string };
// { name: "数模之星 冠军", detail: "答辩前三名：冠军、亚军三万、季军两万", money: "50000", accent: COLORS.red }

export type Track = { name: string; start: string; end: string; span: string; accent: string; warn?: string };

export type DayBlock = { day: string; date: string; focus: string; pct: number; accent: string };
// { day: "D1", date: "9/23", focus: "读题、选题、定技术路线", pct: 25, accent: COLORS.red }

export type SectionType =
  | "countdown" | "timeline" | "cards" | "versus" | "ladder"
  | "gantt" | "alert" | "blocks" | "checklist" | "follow";
```

### 版式序（参考真源）
```
countdown → timeline → cards → versus → ladder → gantt → alert → blocks → checklist → follow
```
规律：**紧急前置**（countdown 打头）→ **事实铺开**（timeline/cards/versus/ladder）→ **风险提示**（gantt/alert）→ **行动指引**（blocks/checklist）→ **收尾**（follow）。

## 4. 风格 DNA

**完全沿用 T1 的深空学术配色**（`theme.ts` 同一套 `COLORS`、`SANS`、`SERIF`、`GRA`），只是版式不同。
所以 T5 可以理解为「**T1 的骨架 + 10 种资讯版式**」。

差异点：
- 场景数固定 10，每场景更短（约 18–20s）
- accent 分布更散——资讯类每个信息点一个色，不要连续两场同色
- 数字出现频率高（日期、金额、百分比），**全部要中文读法**

---

## 5. 内容要求

### 5.1 必查项（资讯类最容易过期）
| 项 | 怎么做 |
|---|---|
| 报名截止日 | 联网核实官方最新通知，**不沿用记忆里的日期** |
| 赛程节点 | 逐条对官方日程表 |
| 奖项金额 | 对官方奖励办法原文 |
| 参赛资格 | 对官方报名条件 |
| 违规罚则 | 对官方纪律规定原文 |

⚠️ 资讯类视频的**时效性就是生命**。S3 的事实核对表在这档要做得最细，每条都要有「出处 + 原文摘录 + 核实日期」。

### 5.2 标题打法（用户已验证的套路）
标题里保留赛事关键词（如「华为杯」），做搜索和推荐都能进对池子。三种打法各出一条：
- **主题前置型**：「华为杯研赛 9 月 19 日截止报名，别错过」（20 字）
- **痛点 + 主题型**：「华为杯报名只剩最后两天：奖金最高五万」（19 字）
- **数字型**：「华为杯研赛：一百小时、六道题、五万奖金」（19 字）

### 5.3 结尾
用 `follow` 版式做关注引导，不要硬塞清单。

## 8. 复用提醒

10 种版式里，`timeline` / `ladder` / `gantt` / `versus` / `alert` 是最通用的五个，**值得抽成独立组件回灌到 `风格规范\template\`**。

# T1 · 深空学术 × 玻璃拟态（信息密度档）

> **系列正片主力档。** 6+1 种版式承载高信息密度，颜色即语义。
> 真源：`第十二期_论文逐段实战\项目源码\mcm-video-temp\`、`风格规范\template\`

---

## 1. 适用 / 不适用

| ✅ 适用 | ❌ 不适用 |
|---|---|
| 方法对比、错误 vs 正确 | N 条清单、考前急救（→ T2） |
| 流程 / 动线 / 时间分配 | 一道真题完整求解（→ T3） |
| 公式推导、三步口诀 | 论文图逐张讲解（→ T4） |
| 评分细则、自查清单 | 赛事资讯（→ T5） |
| 时长 185–195s，信息量大 | 时长 < 2 分钟（→ T2） |

**判断**：内容能不能用「编号 + 一句话」表达？**不能** → 用本档。

## 3. 风格 DNA

### 3.1 色板（`theme.ts` 的 `COLORS`，唯一真源）

| 角色 | 值 | 用途 |
|---|---|---|
| `bg0` | `#070B18` | 主底色 |
| `bg1` | `#0D1428` | 背景渐变中段 |
| `bgEnd` | `#05070F` | 渐变收尾（比 bg0 更深） |
| `text` | `#EEF2FF` | 主文字 |
| `dim` | `#9AA6C4` | 次要文字 |
| `faint` | `#6B7796` | 角标 / 最弱文字 |
| `glass` | `rgba(255,255,255,0.055)` | 玻璃卡底 |
| `glassStrong` | `rgba(255,255,255,0.09)` | 强玻璃卡底 |
| `line` | `rgba(255,255,255,0.13)` | 描边 |
| `ink` | `#08101F` | 放在亮色胶囊上的深字 |

**语义色（亮版 / 深版配对，深版只用于渐变第二站）**：

| 语义 | 亮 | 深 | 含义 |
|---|---|---|---|
| 红 | `#FF3B5C` | `#C41F3C` | 扣分 / 危险 |
| 青 | `#22D3EE` | `#0E8FA6` | 加分 / 正确 |
| 黄 | `#FFD54A` | `#D97706` | 强调 / 关键数字 |
| 橙 | `#FB923C` | `#C2410C` | — |
| 蓝 | `#4C8DFF` | `#2563EB` | — |
| 紫 | `#A78BFA` | `#7C3AED` | — |
| 绿 | `#34D399` | `#0F9B6C` | — |
| 琥珀 | `#FFB020` | `#B45309` | — |

**颜色即语义**（贯穿全片）：红 = 扣分 / 错，青 = 加分 / 对，黄 = 强调 / 关键数字。评委读法、对错对比、清单编号全靠这套色码，**不需要额外图例**。

**渐变公式**：`GRA(a, b) = linear-gradient(135deg, a, b)`；`gradOf(accent)` 自动取对应深版。

### 3.2 字体
```
SANS  = "'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', 'Source Han Sans SC', sans-serif"
SERIF = "'Noto Serif SC', 'Songti SC', 'SimSun', serif"
```
- **大数字、大标题** → `SERIF`（宋体系，学术感）
- **正文、标签、清单** → `SANS`
- 字重：大数字 900、标题 900、副标题 800、正文 600 / 500
- 横竖版统一缩放 `fontK = isPortrait ? (width/1080)*0.94 : width/1920`
  标题 `60*fontK`、正文 `28*fontK`、标签 `22*fontK`

### 3.3 背景四层（固定堆叠顺序，别乱）
```
① backgroundColor: bg0
② linear-gradient(155deg, bg0 0%, bg1 60%, bg0 100%)
③ 双径向光晕（本章 accent 染色）
     radial-gradient(900px 620px at 82% 8%,  accent26 0%, transparent 62%)
     radial-gradient(700px 520px at 12% 92%, accent1A 0%, transparent 60%)
④ 细网格：双 linear-gradient 1px 线，backgroundSize: 52px 52px
⑤ 顶部 8px + 底部 8px 的 accent 渐变条（章节标识）
```
`accent26` = hex 后加透明度后缀（`26`≈15%，`1A`≈10%）。
**每换一个场景 accent 变化，整片背景光晕跟着变色**——这是这套风格最省事的层次来源。

## 4. 七种版式

| 类型 | 组件 | 结构 | 数据字段 |
|---|---|---|---|
| `hook` | `HookView` | 3 张玻璃数字卡横排（竖版竖排），数字 128/132px | `nums` |
| `number` | `NumberView` | 空心大数字 + 标题 + 竖条 punch（从 T2 并入） | `num` / `punch` / `tone` |
| `route` | `RouteView` | 比例时间条（`flexGrow=w`）+ 下方图例胶囊 + 底部注释 | `route` / `routeNote` |
| `compare` | `CompareView` | 顶部编号胶囊 + 左红「扣分」/ 右青「加分」双栏（竖版堆叠） | `compare` |
| `formula` | `FormulaView` | 3 张玻璃卡，字母 78/86px，中间 `→`（竖版 `↓`） | `formula` |
| `checklist` | `ChecklistView` | N 条编号卡纵向堆叠，逐条左滑入 | `checklist` |
| `text` | 内联 | 口播逐句浮现（outro 用） | — |

**第十三期新增两个变体**（需时手工加）：
- `redline`：大数字 + 三条禁令
- `cards`：三卡片

**场景统一骨架**（所有版式共用）：
```
① 头部：左「第 NN 节 · kicker」渐变胶囊（深字）  右「数模真题拆解 · 第N期」faint 角标
② 标题：居中 900 字重，下方 92×6 渐变短下划线
③ 正文区：flex:1，按 type 分派版式
④ 底部：6px 进度条（宽 = sec/total*100%）+ 字幕条
```

## 5. 字幕条

**按句长权重分配时段，不要按均分**（这是老做法，词边界做法优先）：
```ts
weight = s.replace(/\s/g,"").length
spans[i] = weight[i] / totalWeight * 0.86        // 0.86 = 字幕在场景内的可用宽度
segStart[i] = 累加                                // 天然单调，不会越界
```
样式：底部居中，`marginBottom: innerH*0.075`，底 `rgba(7,11,24,0.80)`，圆角 `fs*0.4`，
`boxShadow: 0 10px 34px rgba(0,0,0,0.5)`，横版 `fs=38` / 竖版 `fs=46`。
每句进出做 `fadeIn * fadeOut` 双向淡 + 16px 上浮。

> **2026-09-10 起改用词边界实时刻 + 硬切无动画**，与音频轨逐词对齐。细节见 `references/pipeline.md` 第 5 节。

## 6. 封面公式

`EpisodeCover.tsx`（4:3 / 3:4 由 `ratio` 一个 prop 切换）：

```
① 顶部标签行：黄底深字胶囊「数模真题拆解 ⑫」+ 灰字副标
② 三连数字卡：30 / 5 / 7，128px 宋体 900，各带 1px 语义色描边
③ 主标题 84~96px 宋体 900 + 110×7 红→黄渐变短下划线 + 两行灰字副标
④ 要点胶囊行：ROUTE 前 4 项 + 「等 7 处」
⑤ 顶部 10px 红→黄→青渐变条 + 底部 10px 青→黄→红渐变条（镜像）
```

⚠️ 封面**必须复用视频的 hook 数字**（如 30/5/7），缩略图上的数字和片头要对得上。

数据里改这两处即可：
```ts
export const BRAND = { corner: "数模真题拆解 · 第 N 期" };
export const COVER = { tag, tagSub, title, sub, chips, chipsTail };
```

## 7. 执行清单

```powershell
npm install                                  # 首次（或 junction 复用）
# 用已装 edge-tts 的解释器跑（APP 内置环境已预装；自装环境先 pip install edge-tts）
python _gen_tts.py      # ① 配音 + 混音 + timing.json
npx remotion studio src\remotion\index.ts    # ② 逐场景目检
npx remotion render src\remotion\index.ts EpisodeLandscape out\横版.mp4 --gl=angle
npx remotion render src\remotion\index.ts EpisodePortrait  out\竖版.mp4 --gl=angle
npx remotion still  src\remotion\index.ts Cover43          out\封面4比3.png
npx remotion still  src\remotion\index.ts Cover34          out\封面3比4.png
```

- 第十二期《论文逐段实战》11 场景 189.65s 5690 帧，rate +28%（⚠️ 漏做后处理两关，别照抄）
- 第十三期《交卷之后》11 场景 185.28s 5558 帧，rate +28%，新增 redline / cards 版式，后处理已补

## 8. 换期只动 3 个文件

| 文件 | 改什么 |
|---|---|
| `src\remotion\episode_data.ts` | 内容 + 配色。`SECTIONS[]` 每场景一条，`VOICE_TEXTS` 同名对应，`BRAND.corner`、`COVER` |
| `videos\<ep>\podcast.txt` | 口播稿，`[SECTION:name]` 分块 |

其他（`theme.ts` 设计令牌、`EpisodeVideo.tsx` 版式引擎、`EpisodeCover.tsx` 封面、`Root.tsx` 4 个输出）是骨架，换期不用动。
